### Verification limitation in this workspace

The sandbox has outbound network access limited to `github.com`,
`api.github.com`, `codeload.github.com`, `registry.npmjs.org`, `pypi.org` and
`files.pythonhosted.org`. Requests to `analysis-tool-82jq.onrender.com` fail at
the TLS handshake (`SSL_ERROR_SYSCALL`), so the live site **could not be fetched
or diffed from here**.

Consequence: baseline behaviour was established from the repository source
(which is what Render builds), and parity is asserted against the legacy code
itself rather than against scraped HTML:

* golden values are generated by executing `src/utils/statistics.ts` under Node
  (`site/tests/golden/generate_golden.mjs`);
* config parity tests read constants straight out of `src/**/*.tsx`
  (`site/tests/test_config.py`);
* the icon sprite is extracted from `lucide-static@0.563.0`, the release
  `lucide-react@^0.563.0` resolves to.

Before cutover, a human should load both URLs side by side and confirm the
checklist in `render.md` § 5.

## 3. Baseline behaviour (from source, per view)

**Overview** (`DataOverview.tsx`) — drag & drop or click-to-browse upload for
`.xlsx/.xls/.csv`; "Generate Sample Dataset" builds 200 rows × 10 columns
(`id, product, category, region, month, sales, quantity, price, rating, inStock`)
with `Math.random()`; once loaded, a gradient card shows file name, rows,
columns, upload time and `~KB` estimate (`JSON.stringify(data).length / 1024`),
plus a numbered column chip list and a "Clear & Upload New" button.

**Data Table** (`DataTable.tsx`) — 15 rows per page, five-slot pagination window,
cross-column case-insensitive search, click-to-sort with nulls last and a numeric
fast path, `#` row numbering, "Showing X - Y of Z rows".

**Statistics** (`Statistics.tsx`) — six gradient summary cards (rows, columns,
numeric cols, categorical cols, missing values, missing %) and one expandable
card per column: count/unique/missing plus mean, median, mode, min, max, range,
sum, std dev, variance, Q1, Q3, IQR, skewness, kurtosis for numeric columns;
most/least common for string and mixed columns. Integers print raw; floats print
with `toFixed(4)`.

**Probability** (`Probability.tsx`) — Basic (P(A), plus C(n,r) and P(n,r) with an
`n ≤ 170` guard showing `N/A`), Binomial (P(X=k), μ, σ), Poisson (P(X=k), μ, σ),
Normal/Z (z-score, PDF), Correlation (Pearson r with Strong/Moderate/Weak +
Positive/Negative label, covariance, R²) over two numeric columns.

**Visualization** (`Visualization.tsx`) — bar, line, area, pie, scatter,
histogram; X/Y/aggregation selects (sum, avg, count, min, max); aggregation
sorted descending and capped at 50 categories; scatter capped at 500 points;
histogram bins `min(20, ceil(sqrt(n)))` with an inclusive last edge; pie capped
at 12 slices with percentage labels and a legend; 18-colour palette.

**Shell** (`App.tsx`) — 256px white sidebar (logo, nav, dataset status card),
mobile drawer with overlay, header with per-tab title and subtitle. Data lives
only in React state, so a page reload starts empty.
